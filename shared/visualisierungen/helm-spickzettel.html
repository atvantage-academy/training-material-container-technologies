Spickzettel: Helm

    Spickzettel: Helm

    Die wichtigsten Helm-Befehle zum Nachschlagen. Wo sich klassische Repositories und OCI-Registries unterscheiden, stehen beide nebeneinander. Was Chart, Release und Values sind, erklärt Helm Charts.

    OCI ist ab Helm 3.8 stabil. Ältere Versionen kennen nur die klassischen Repository-Befehle. Welche Version Du hast, zeigt helm version.

    Quellen

    Repositories, Registries, Suche

    Installieren

    install, --set, -f

    Releases

    list, status, get, history

    Upgrade und Rollback

    upgrade, rollback, uninstall

    Chart entwickeln

    create, lint, template

    Quellen: Repository oder Registry

    Aktion Klassisch (alle Versionen) OCI (ab Helm 3.8)
    Quelle einrichten helm repo add bitnami https://charts.bitnami.com/bitnami helm registry login ghcr.io
    Quelle aktualisieren helm repo update – (die Registry liefert stets den neuesten Stand)
    Quellen auflisten helm repo list –
    Quelle entfernen bzw. abmelden helm repo remove bitnami helm registry logout ghcr.io
    Charts suchen helm search repo postgresql – (Oberfläche der Registry oder Artifact Hub)
    Alle Versionen eines Charts helm search repo postgresql --versions –
    Auf Artifact Hub suchen helm search hub postgresql helm search hub postgresql

    Hinweis: OCI-Registries brauchen kein helm repo add – Du sprichst ein Chart direkt über seine Adresse oci://… an.

    Charts herunterladen und ansehen

    Aktion Klassisch OCI
    Als .tgz herunterladen helm pull bitnami/postgresql helm pull oci://ghcr.io/myorg/my-app --version 1.0.0
    Herunterladen und entpacken helm pull bitnami/postgresql --untar helm pull oci://ghcr.io/myorg/my-app --version 1.0.0 --untar
    Infos zum Chart helm show chart bitnami/postgresql helm show chart oci://ghcr.io/myorg/my-app --version 1.0.0
    Standard-Values helm show values bitnami/postgresql helm show values oci://ghcr.io/myorg/my-app --version 1.0.0

    Charts veröffentlichen

    Aktion Klassisch OCI
    Als .tgz verpacken helm package ./my-app helm package ./my-app
    Hochladen hängt vom Server ab (ChartMuseum-API, GitHub Pages, Nexus …) helm push my-app-1.0.0.tgz oci://ghcr.io/myorg

    Charts installieren

    Aktion Befehl
    Aus einem lokalen Verzeichnis helm install my-release ./my-app
    Aus einem klassischen Repository helm install my-release bitnami/postgresql
    Aus einer OCI-Registry helm install my-release oci://ghcr.io/myorg/my-app --version 1.0.0
    Mit eigener Values-Datei helm install my-release ./my-app -f prod-values.yaml
    Einzelne Werte überschreiben helm install my-release ./my-app --set replicas=3 --set image.tag=1.2.3
    In einen bestimmten Namespace helm install my-release ./my-app -n my-namespace
    … und den Namespace dabei anlegen helm install my-release ./my-app -n my-namespace --create-namespace
    Nur rendern, nicht installieren helm install my-release ./my-app --dry-run

    Hinweis: In der Schulungsumgebung arbeitest Du in Deinem eigenen Project bzw. Namespace und darfst meist keine neuen anlegen – --create-namespace scheitert dort an den Rechten.

    Releases verwalten

    Aktion Befehl
    Installierte Releases auflisten helm list
    … in allen Namespaces helm list -A
    Status eines Release helm status my-release
    Aktuelle Values eines Release helm get values my-release
    Alle erzeugten Manifeste helm get manifest my-release
    Historie der Revisionen helm history my-release

    Upgrade, Rollback und Entfernen

    Aktion Befehl
    Release upgraden (lokales Chart) helm upgrade my-release ./my-app
    … mit geänderten Values helm upgrade my-release ./my-app -f prod-values.yaml
    Upgraden oder, falls nicht vorhanden, installieren helm upgrade --install my-release ./my-app
    Auf die vorige Revision zurück helm rollback my-release
    Auf eine bestimmte Revision zurück helm rollback my-release 2
    Release entfernen (mit allen Ressourcen) helm uninstall my-release
    … in einem bestimmten Namespace helm uninstall my-release -n my-namespace

    Ein Chart entwickeln

    Aktion Befehl
    Neues Chart-Gerüst anlegen helm create my-app
    Chart auf Fehler prüfen helm lint ./my-app
    Templates lokal rendern (ohne Cluster) helm template my-release ./my-app
    … mit eigenen Values helm template my-release ./my-app -f prod-values.yaml
    Dependencies (Subcharts) herunterladen helm dependency update ./my-app
    Dependencies auflisten helm dependency list ./my-app
    Tests eines Release ausführen helm test my-release

    Klassisch und OCI auf einen Blick

    Aktion Klassisch OCI (ab 3.8)
    Quelle einrichten helm repo add <name> <url> helm registry login <registry>
    Suchen helm search repo <stichwort> Oberfläche der Registry / Artifact Hub
    Herunterladen helm pull <repo>/<chart> helm pull oci://<registry>/<chart> --version <x>
    Veröffentlichen je nach Server helm push <chart>.tgz oci://<registry>
    Installieren helm install <release> <repo>/<chart> helm install <release> oci://<registry>/<chart> --version <x>
    Infos zum Chart helm show chart <repo>/<chart> helm show chart oci://<registry>/<chart> --version <x>
