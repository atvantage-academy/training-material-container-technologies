    Ein Python-Skript im Container ausführen

    Als Entwickler möchte ich ein Skript ausführen, ohne Python zu installieren, damit es auf jedem Rechner gleich läuft.

    Lernziele

    Du…

    • suchst Dir selbst ein Image, das eine bestimmte Laufzeitumgebung mitbringt.
    • bringst eine Datei von Deinem Rechner in einen Container.
    • führst eine Anwendung in einem Container aus, ohne einen Container zurückzulassen.
    • erklärst, wo Dein Skript liegt – im Image oder daneben.

    Definition of Done

    • Das Skript läuft in einem Container und gibt seine Zeile aus.
    • Auf Deinem Rechner ist kein Python installiert worden.
    • Nach dem Lauf ist kein Container übrig (docker container ls -a).

    Dein Auftrag

    Diese Übung nennt kein einziges Kommando. Das ist Absicht: Du hast alles gesehen, was Du brauchst – den Rest findest Du in der Referenz.

    Leg eine Datei hello.py an, mit dem Editor Deiner Wahl:

    print("Hallo aus dem Container!")

    Bring sie in einem Container zur Ausführung. Am Ende solltest Du Hallo aus dem Container! auf der Konsole sehen, und der Container selbst ist nach der Ausführung wieder gelöscht. Es gibt mehr als einen Weg.

    Hinweis: Welches Image die passende Laufzeitumgebung mitbringt, suchst Du Dir selbst – auf Docker Hub wirst Du fündig.

    Hinweis: Gesucht ist ein Aufruf der Form docker container run --rm …. Ab dieser Übung ist das der Normalfall: Ohne --rm sammeln sich beim Ausprobieren Container an, die niemand mehr braucht.

    Reflexionsfragen

    Hier gibt es nichts aufzuschreiben – was Du gefunden hast, besprechen wir gemeinsam.
