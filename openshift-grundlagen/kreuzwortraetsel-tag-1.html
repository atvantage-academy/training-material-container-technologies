    Kreuzworträtsel: Tag 1

    Der erste Tag hat viele neue Begriffe gebracht. Dieses Rätsel holt sie zurück – am besten gemeinsam, zum Start in den zweiten Tag. Die markierten Felder ergeben das Lösungswort: das, was Kubernetes mit Deinen Containern macht.

    Kleinste deploybare Einheit in Kubernetes
    Beschreibt den Soll-Zustand von Pods, inklusive der Anzahl der Replicas
    Stabiler Netzwerk-Endpunkt für eine Gruppe von Pods
    Macht einen Service in OpenShift von außen erreichbar
    oc _____ -f übergibt den gewünschten Zustand an den Cluster
    Sorgt dafür, dass immer die gewünschte Anzahl Pods läuft
    Die gesamte Infrastruktur aus Control Plane und Worker Nodes
    Maschine im Cluster, auf der Pods ausgeführt werden
    Laufende, isolierte Instanz eines Images – bekannt aus Docker
    Agent auf jedem Node, der die Container startet und überwacht
    Komponente der Control Plane, die neue Pods den Nodes zuweist
    Verteilte Key-Value-Datenbank – das Gedächtnis des Clusters
    Isolierter Bereich in Kubernetes – in OpenShift heißt er Projekt
    Zentraler Ablageort für Container-Images, etwa Docker Hub
    YAML-Datei, die eine Ressource deklarativ beschreibt
    Ressource für nicht sensible Konfiguration als Schlüssel-Wert-Paare
    Ressource für sensible Daten wie Passwörter – nur Base64-kodiert, nicht verschlüsselt
    Häufigster Weg, Konfiguration in einen Container zu geben: _____-Variable
